# hid-proxy-controller

HID Proxy Controller - A Python application for HID device proxying and emulation.

## Structure

```
hid-proxy-controller/
├── src/
│   └── hid_proxy/
│       ├── __init__.py
│       ├── __main__.py
│       ├── app.py
│       ├── config/
│       ├── core/
│       ├── modules/
│       ├── targeting/
│       ├── ui/
│       ├── system/
│       └── utils/
├── build/
├── pyproject.toml
├── requirements.txt
└── README.md
```

## Installation

```bash
pip install -e .
```

## Usage

```bash
python -m hid_proxy
```
